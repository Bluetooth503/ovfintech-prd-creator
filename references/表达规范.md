# 表达规范（S3 自由文本去模板腔）

> 用途：成文后的**表达自检**，只作用于 S3 自由文本（背景、痛点、目标、方案取舍、叙述性处理逻辑、备注里的论述段）。
> 与《写作总则》一致：短句 + 编号 + 直述；删形容词副词；不写宣传语。

## 1. 适用与豁免

**适用**：S3 自由文本——1.1 背景/痛点/目标、方案取舍、2.x 叙述性「处理逻辑」、备注说明的论述段。

**豁免（一个字不改）**：S1 表格（功能清单、术语、输入输出、业务规则、评审、变更）、S2 骨架固定字段名与「不适用」声明，以及 **术语、字段名、业务规则文本、提示原话、数值、状态名、枚举取值、引用原文**。

目标是压掉「像模型在表演写作」的腔调，不是把 PRD 写口语。专业文本可以专业。

## 2. 保护域（先划，再改）

改写前先圈出不能动的：术语与专业名词、系统主语、命令/字段/状态名、提示原话、数字与其修饰对象、责任主体与动作配对。

只允许删句、并句、降调、换主语、去收尾；**不新增事实、不删核心事实、不改口径**。

## 3. 高危句式壳（优先清）

| # | 句式壳 | 处理 |
|:--|:--|:--|
| 1 | 二元对比壳：不是 A 而是 B / 不在于 A 而在于 B | A 是废话就删掉直说 B；都有用就写成具体关系 |
| 2 | 本质论断壳：真正重要的是 / 本质上 / 核心在于 / 底层逻辑 | 点名实际主语，用证据、动作、后果替代抽象强调 |
| 3 | 助手路线标记：下面我们 / 接下来 / 总的来说 / 值得注意的是 / 说白了 | 直接进入内容，删除 |
| 4 | 阶段推进壳：先 A 再 B / 第一步…第二步… | 叙述层清掉仪式感排序（**操作步骤/SOP 的顺序是正当的，保留**） |
| 5 | 收窄与易答：这个问题很简单 / 这次只看… | 去掉铺垫，或换成具体条件 |
| 6 | 无动机结尾问句：你觉得呢 / 是不是很有启发 | 默认删除 |
| 7 | 模板化标点与段落：`概念：解释` 式冒号滥用；观点+解释+总结循环；三段同语法排比 | 冒号只在自然需要时用；段落长短错落，打破整齐排比 |

另：宣传与黑话（赋能、闭环、抓手、生态、颠覆、助力、打造、全方位）一律删（《写作总则》已禁）。

## 4. 段落节奏

- 一句一件事；能用编号就编号。
- 段落重量错落：短拍 → 中解释 → 厚段 → 短落点；不要每段等长、同语法、同情绪。
- 段落尽量以事实、条件、后果收尾，不用总结句或口号收尾。

## 5. 流程与回读（固定两步）

1. **保真回读**：保护域是否漂移；数字与修饰对象的配对、主体与动作配对、谓词方向/完成态是否变。句内改写后字数低于原文 85% 时，回查是否误删事实。
2. **残留审计**：只查开场残留、总结残留、空泛判断残留、节奏过匀；只做轻量修正，**不重写全文、不补事实、不改术语与责任归属**。

默认只做第 1 步；若继续改会变口语、变广告或影响保真，就停。

## 6. 输出与登记

- 默认只给修订后的正文，不输出审稿过程。
- 改动了 S3 段落时，在「变更说明」中登记（改了哪些段、为什么），保证可追溯。
